# TicTacToe Web Game 🎮

Welcome to the ultimate battle of X’s and O’s!
This is a fun, simple browser TicTacToe game built with plain HTML, CSS, and JavaScript.

## Tech Stack

- **HTML5 - Structure of the game board and UI.**
- **CSS3 – Styling and responsive layout.**
- **JavaScript – Game logic and interactivity.**

## Features

- **Classic TicTacToe gameplay (Player vs Player).**
- **Dynamic board updates with winning logic.**
- **Clean and responsive UI for web browsers.**
- **Reset functionality to start a new match instantly.**
